# 00-laws-start — 관계법령 입구

국가법령정보센터 현행 법령을 주제별 스킬로 나눈 컬렉션들의 입구다.
「감정평가 실무기준」 컬렉션(`appraisal-practice-standards`)에서 "감정평가관계법규에 따로 정한 것", "관계법규 확인 필요"가 나오면 여기로 온다.

## 컬렉션 고르기

| 컬렉션 | 입구 | 이럴 때 |
|---|---|---|
| A층 · 토지보상법 | [00-lca-start](../land-compensation-act/00-lca-start/SKILL.md) | 공익사업의 협의취득·수용·사용 절차, 손실보상(토지·물건·권리·영업·농업·이주대책·사업지구 밖 보상), 이의신청·환매권 |
| A층 · 감정평가법·감정평가에 관한 규칙 | [00-apa-start](../appraisal-act/00-apa-start/SKILL.md) | 감정평가의 기준·의뢰·감정평가서·심사·타당성조사, 감정평가사·법인·협회·징계. 평가규칙: 감정평가 원칙·절차·물건별 방법 |
| A층 · 부동산공시법 | [00-pda-start](../price-disclosure-act/00-pda-start/SKILL.md) | 표준지·개별공시지가, 주택가격, 비주거용 부동산가격의 조사·평가·공시·이의신청 |
| A층 · 국토계획법 | [00-nlp-start](../national-land-planning-act/00-nlp-start/SKILL.md) | 용도지역·지구·구역과 건축제한·건폐율·용적률, 도시·군계획시설, 지구단위계획, 개발행위허가 |
| A층 · 도시정비법 | [00-ura-start](../urban-redevelopment-act/00-ura-start/SKILL.md) | 재개발·재건축 절차, 조합, 사업시행계획, 관리처분계획(종전·종후자산), 매도청구, 수용, 청산 |
| B층 · 관련 조항 | [00-rel-start](../related-provisions/00-rel-start/SKILL.md) | 실무기준·토지보상법 시행규칙이 조문 번호로 인용한 다른 법령 조항(건축법, 수산업법, 광업법, 통계법 등) |
| C층 · 공익사업 근거법 연결 조항 | [00-pwa-start](../public-works-acts/00-pwa-start/SKILL.md) | 토지보상법 별표의 근거법 115개(도로법·도시개발법·택지개발촉진법·하천법 등)가 토지보상법을 언급하는 조항: 수용 권한, 사업인정 의제, 재결신청 기간 특례, 준용 |
| 절차 · 법령 간 연결 | [workflow-compensation-chain](../workflow-compensation-chain/SKILL.md) | 근거법 → 토지보상법 → 실무기준(또는 역방향)으로 수용·보상 사건을 따라갈 때 |

- **A층**: 법·시행령·시행규칙의 모든 조문을 수록하고 요약했다.
- **B층**: 인용된 조항만 수록했다.
- **C층**: 토지보상법을 언급하는 조항만 기계적으로 골라 수록했다.
- 범위를 정한 기준은 `laws/README.md` 에 있다.
- 어느 스킬에서든 "참조 관계"(나가는 연결)와 "들어오는 연결"로 다른 컬렉션과 오갈 수 있다.

## 읽는 법

1. 컬렉션 입구의 주제 지도에서 주제 스킬을 고른다.
2. 주제 스킬의 `SKILL.md` 를 읽고, 결론과 인용은 `source.md`(원문)로 확인한다.

원문 확인, 인용 형식(`법 제70조제1항`·`영 제38조의2`·`규칙 제22조`·`평가규칙 제14조`), 규범 우선순위, 판본, 별표 가공본의 의미는 [skill-reading-rules](../../rules/skill-reading-rules/SKILL.md) 를 따른다.
실무기준·관계법령 개정에 따른 스킬 갱신은 갱신 지시를 받았을 때만 [skill-update-maintenance](../../rules/skill-update-maintenance/SKILL.md) 를 따른다.
