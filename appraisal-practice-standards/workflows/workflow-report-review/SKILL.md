# workflow-report-review — 감정평가서 검토·심사

이미 작성된 감정평가서가 실무기준에 맞는지 볼 때 쓴다.

먼저 검토의 성격을 가린다.
- **일반 검토**(동료 검토, 의뢰인 측 검토 등): 아래 1–4, 6을 한다.
- **감정평가법인의 적정성 심사**(발급 전 같은 법인 소속 다른 감정평가사의 심사 [500-4-②]): 5까지 모두 한다.
동료 검토를 법정 심사로 가정하지 않는다.

## 절차

1. **적용 규정을 정한다**: 평가서의 목적·대상물건·기준가치·조건·기준시점을 [workflow-appraisal/facets.md](../workflow-appraisal/facets.md) 에서 찾아 특칙·물건 스킬을 바로 고른다.
   특칙이 둘 이상이거나 물건이 여럿이면 [workflow-appraisal](../workflow-appraisal/SKILL.md) 2단계·2-1단계를 따른다.
   평가서에서 결정 사실이 드러나지 않으면 그 자체를 지적 사항으로 적는다.
   - 고른 특칙·물건 스킬의 `## 적용 시 확인사항` 이 그대로 검토 체크리스트다. 특칙 고유 확인사항을 먼저 본다.
   - 예: 재무보고라면 자산분류 기준 일치와 소유권 제한 확인 [740-2-②], 기준가치는 공정가치 [740-3]
2. **기본적 사항과 원칙**:
   - [ ] 의뢰인·대상물건·목적·기준시점·조건·기준가치 등이 계약 기본사항([300-3-①])과 맞는다.
   - [ ] 기준시점이 [300-4]에 맞는다. 미리 정한 날이면 그 이유가 기재돼 있다([300-4-③]).
   - [ ] 감정평가조건이 있으면 부가 근거와 검토사항, 조건을 전제로만 성립한다는 사실이 표시돼 있다([300-5.2]·[300-5.3]).
   - [ ] 시장가치 외의 가치면 [400-2.1-③] 검토가 있다.
   - [ ] 현황기준·개별물건기준 원칙([400-2.2]·[400-2.3])의 예외에 근거가 있다.
3. **방법과 결정** — 스택의 특칙 → 물건 순서로 해당 스킬의 "적용 시 확인사항"을 체크리스트로 쓴다.
   - [ ] 주된 방법을 적용했다. 다른 방법을 썼다면 주된 방법이 곤란·부적절한 사정이 있다 [400-4-①].
   - [ ] 다른 방식의 방법으로 산정한 시산가액과 비교해 합리성을 검토했다. 검토하지 않았다면 곤란·불필요한 사유를 평가서에 기재했다 [400-4-②].
   - [ ] 시산가액을 조정했다면, 그것은 합리성이 없다고 판단된 경우의 재량이다 [400-4-③]. 조정했으면 목적·특성·자료 신뢰성·시장상황을 고려한 가중치가 있다 [400-4-④].
   - [ ] 보정·예외에 요구되는 근거 기재가 있다. 예: [610-1.5.2.5]의 그 밖의 요인 보정 근거
4. **감정평가서 형식**:
   - [ ] 작성원칙 [500-1], 형식과 제목 [500-2], 기재사항 [500-3]
   - [ ] 서명과 날인 [500-4-①]
   - [ ] 발급 및 보존 [500-5]
   - [ ] 관련 전문가를 활용했으면 [300-6-④] 기재
5. **적정성 심사**(감정평가법인): [500-4-②–④]가 정한 심사 범위와 수정·보완 절차를 확인한다.
   - 심사 범위: 위산·오기, 관계법규에 따른 적정한 감정평가 여부
   - 심사 사실 표시
6. **기록**: 지적 사항마다 다음을 적는다.
   - 해당 조항 표기, 평가서의 해당 부분, 근거 원문 인용
   - 구분: 의무 위반("하여야 한다")인지 재량 판단("할 수 있다")에 대한 의견인지
