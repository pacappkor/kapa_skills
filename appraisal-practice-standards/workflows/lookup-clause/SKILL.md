# lookup-clause — 조항 찾기

"~란?", "~는 어떻게 평가하나", "근거 조항은?" 같은 질문에 쓴다. 다른 작업 절차에서 모르는 낱말이 나올 때도 쓴다.

@skills 논문(arXiv:2608.12610)이 지적하듯, 경로는 스킬에 주소를 붙일 뿐 찾아 주지는 않는다.
그래서 이 컬렉션은 찾기를 결정적으로 할 수 있게 두 가지를 준비했다.
- 생성 색인: [terms.md](terms.md)
- 원문 전문: 각 스킬의 `source.md`

임베딩 검색 같은 확률적 방법은 쓰지 않는다. 같은 질문이면 같은 조항이 나와야 한다.

## 절차

1. **용어 색인**: 질문의 낱말로 [terms.md](terms.md) 를 검색한다(grep).
   원문 정의 용어와 한 번만 쓰인 조항 제목 약 400개가 조항·스킬로 연결돼 있다.
   - 예: `맹지` → [610-1.7.12] asset-land
   - 예: `입체이용저해율` → [820-3]·[820-5.2.2.1] overlay-compensation-land-use
2. **원문 전문 검색**: 색인에 없으면 원문을 검색한다. 활용형·띄어쓰기를 바꿔 가며 검색한다.
   - 예: `grep -rn "<낱말>" appraisal-practice-standards --include=source.md`
   - 정의 조항이 아니라 본문에만 나오는 말(예: "공정가치" [740-3-②])도 이렇게 찾는다.
3. **물건·목적 이름으로 물을 때**: [workflow-appraisal/facets.md](../workflow-appraisal/facets.md) 의 조회표를 본다.
4. **인용 따라가기**: 찾은 스킬 SKILL.md 끝의 "참조 관계"를 따라간다.
   - 원문이 다른 조항을 "준용"하거나 "따른다"고 하면 그 조항까지 읽어야 답이 완결된다.
   - 예: [620-1.3.3] 공장의 기계기구류 → [630-1] asset-machinery
   - 예: [660-1.2.3-②] 비상장주식의 기업가치 → [660-3] asset-enterprise-value
5. **같은 말이 여러 맥락에 있을 때**: 맥락별로 나눠 답하고, 우선순위는 [workflow-appraisal](../workflow-appraisal/SKILL.md) 2단계로 정리한다.
   - 예: 기준시점 — [100-2] 정의, [300-4] 일반, [730-3.1-①] 도시정비 종전자산, [810-5.7] 보상
6. **답하기**: 결론마다 조항 표기를 붙이고, 원문 문장은 `source.md` 에서 그대로 인용한다.
   찾지 못하면 "실무기준에 해당 규정 없음(검색어: …)"이라고 쓴다. 관계법규에 있을 수 있다고 표시한다.
