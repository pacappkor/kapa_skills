# workflow-engagement-check — 수임 판단

의뢰를 받을지, 무엇을 보정받아야 하는지, 이미 받은 의뢰를 철회해야 하는지 판단할 때 쓴다.
평가 수행보다 먼저 한다. 근거 조항은 [foundation-engagement](../../foundations/foundation-engagement/SKILL.md)([300])와
[foundation-ethics](../../foundations/foundation-ethics/SKILL.md)([200])의 `source.md` 에서 확인한다.

## 절차

1. **의뢰서**:
   - [ ] 업무·보수의 구체적 사항이 적힌 의뢰서(전자문서 포함)를 받았다([300-1]).
   - [ ] 기본사항([300-3-①] 각 호)이 빠졌으면 보정을 요구한다.
2. **수임제한**:
   - [ ] [300-2] 각 호의 사유에 해당하는지 확인한다. 불공정 우려, 관계법규·이 기준 위반, 위법·부당한 목적, 조사 불가능, 인력·전문성 부족 등이다.
   - [ ] 해당하면 수임하지 않고 그 이유를 알린다.
   - [ ] 불공정한 감정평가의 내용은 [200-4.2]로 판단한다(친족 소유, 이해관계 등).
3. **기준가치·조건**:
   - [ ] 시장가치 외의 가치를 요청받았으면 [400-2.1-②·③]을 검토한다. 합리성·적법성이 없으면 거부할 수 있다([400-2.1-④]).
   - [ ] 감정평가조건은 [300-5.1]·[300-5.2]의 요건과 검토사항을 확인한다. 합리성·적법성이 없거나 실현 불가능하면 거부·철회할 수 있다([300-7]).
4. **관련 전문가 활용**: 필요하면 [300-6]에 따라 필요성·비용·기간을 설명하고 의뢰인의 동의를 받는다.
5. **윤리**:
   - [ ] 수수료와 실비 외의 대가를 받거나 의뢰 대가로 이익을 제공하지 않는다(청렴 [200-3.3]).
   - [ ] 보수기준을 지킨다([200-3.4]).
   - [ ] 의뢰인에게 설명할 사항을 설명한다([200-4.1]).
   - [ ] 비밀을 지킨다([200-4.3]).
   - [ ] 자동가치산정모형을 쓰면 [200-5]를 확인한다.
6. **철회**: 수임 후 감정평가서 발송 전에 수임제한 사유를 알게 되면 철회해야 한다.
   대상물건의 동일성 문제나 조건 문제는 [300-7] 각 항에 따라 보정을 요구하거나 철회한다.
7. **기록**: 판단마다 조항 표기와 원문 근거를 남긴다. 의뢰서에 없는 사실은 "의뢰인 확인 필요"로 둔다.
   수임하기로 했으면 [workflow-appraisal](../workflow-appraisal/SKILL.md) 로 넘어간다.
